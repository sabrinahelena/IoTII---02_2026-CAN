# BackEnd

Nesta etapa, o firmware utiliza o **Firebase Realtime Database** para armazenar os dados do veículo. Não foi fornecida implementação de API própria.

Os dados ficam em `/telemetria/atual` e `/telemetria/historico`. A forma de acesso pelo aplicativo e as regras de autorização ainda devem ser definidas e comprovadas.
